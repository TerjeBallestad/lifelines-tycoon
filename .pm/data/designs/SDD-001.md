# CA-World onto the Tycoon Shell — Slice 1: The Legibility Pipe

> Rewritten 2026-06-24 after two reviews (code-grounded + official design review). Changes from v1: honest scope (not "smallest slice"; frozen preset; named need-scale unit); definition-of-done retargeted to tycoon's real harness (GUT + rubric evaluator, not a "GATH gate"); the existing desk-fact channel reconciled; PatternRule outputs constrained to observational traces (DD-030/DD-031); the symptom-vs-loop limit named; the matlevering lever deferred; watchability deferral flagged as a deliberate thesis probe.

## Problem

`lifelines-core-loop` couples a living CA simulation to a caseworker desk through a half-finished push→pull migration (`CaseEngineManager.advance_day` → `sim_tick_fn` → `LivingSimTick` → `MatleveringSimTick` + `SimProjection`): vestigial `*SimTick` wrappers, string-identity character matching, the Frank visit bolted on via side-channels, the same outcome derived twice. Two architectures in series; won't refactor clean in place.

`lifelines-tycoon` is a from-scratch, feature-sliced reimagining (~1437 LOC) that already built a clean caseworker-tycoon shell: a pristine `Clock`, a `Sim` reacting to ticks, a `World` orchestrator with gated verbs (diagnostic / intervention / away-action), the trifecta `{trust, dice, knowledge}` economy, scheduled consequences, a read-only return-report Lens, and an `agent_bridge` LLM-playtest harness. But tycoon **stubbed its World**: `Sim.apply_tick` is flat decay — Elling decays, he doesn't live. His `mtg_primary/secondary` identity fields are inert (read only as the hidden answer-key in `agent_bridge`).

This regresses locked intent. SPRINT-014 is *"caseworker layer over the living sim."* SDD-080 locks: *"Existing CA decision engine STAYS… interaction resolution is an orthogonal layer above it."* The living World is what the design always assumed; tycoon's flat decay is the placeholder.

## The Bet

Restore the living World **behind tycoon's read-only Lens**. The Lens reads only observable output and never reaches into sim internals, so swapping flat decay for the CA engine is structurally low-seam *by construction*. **Decision: `lifelines-tycoon` is the go-forward production home;** core-loop freezes, then retires — but **only after** Slice 1's gate passes (core-loop's sandbox stays the tuning oracle until then; see Success Criteria).

## What This Slice Actually Tests (and what it does not)

Riskiest claim under test:

> Does emergent CA output, summarized by authored rules, read as **legible observational facts** at a desk?

**Honest limit — symptom, not loop.** The GDD's real payload is reading a *hidden dependency loop* (Grete over-functions → Elling avoids growth; SDD-090: facts are diagnostic of a loop, deliberately thinner than the witnessed truth). **Grete is out of scope here, so there is no loop to read.** Slice 1 therefore proves **symptom-legibility of one autonomous agent only**. Loop-legibility is a named, deferred risk that depends on a second agent (Slice 3+). A green Slice 1 must NOT be read as de-risking the core promise — only its easy half.

Everything downstream (paid evidence, levers, dice, trust, moment tiltak, watchable diorama, Grete, the loop) is additive and *only worth building if symptoms read first*.

## Scope Honesty

This is **not** the "smallest possible slice." It is the smallest slice that answers the riskiest claim, and it is **substantial**: a full decision-kernel port + a new authored-rule subsystem + a blind-read gate. Complexity is deliberately bounded by three cuts: **frozen Elling preset** (no tuning gym), **no lever** (deferred), **traces not diagnoses** (small rule vocabulary).

## Architecture — the Five Nouns (Slice 1 state)

| Noun | Slice 1 |
| --- | --- |
| **World** | CA decision kernel from `playgrounds/full_ca_sandbox.html`, ported headless. One agent (Elling), **frozen preset** — no exposed tuning. Needs + color identity + per-activity mastery + flow-output + weighted-top-3 (honors DD-029) + overnight reset. **Not** core-loop's 8-subsystem sim. |
| **Lens** | `PatternDeriver` reads a **stable history interface** (not raw engine internals) and emits **observational-trace facts** onto the desk. |
| **Ledger** | tycoon's `CaseFile` (tags) — receives facts unchanged. |
| **Clock** | tycoon's `Clock` — unchanged. |
| **Lever** | **Deferred to Slice 2.** No tiltak perturbs the World in Slice 1 (see Deferred). |

### Need-scale unit (named seam)

The sandbox runs needs on 0–100 with per-need urgency exponents; tycoon's `ClientState.needs` are 0–1. **Decision: the CA engine operates in tycoon's native 0–1 unit;** the sandbox scoring math is ported with deficits computed as `(1 - need)` and exponents retained. No dual scale, no conversion layer. This is called out so it does not become a silent unit seam.

### What ports, precisely

- Extend `ClientState`: per-activity `mastery` map + a 5-float **color-identity vector** (this **replaces** `mtg_primary/secondary` as identity; mtg either derives from the vector or retires — see Ground Truth).
- New `features/sim/ca_engine.gd` (RefCounted): `score_activity(activity, needs, colors, mastery) -> {score, breakdown}` + `select(candidates, rng) -> activity`. Port of sandbox `scoreActivity` + flow-output + weighted-top-3 + jitter, in 0–1 units, seeded RNG.
- New `features/sim/activity.gd` (Resource) + a `Catalog` activity directory; mirror the sandbox `ACTIVITIES` table. **Requires adding `Activity` to `Catalog`'s type allowlist + a `_load_dir` call.**
- Replace `Sim.apply_tick` flat decay: decay needs → on each decision step `CAEngine.select()` applies activity effects + mastery growth → append `(activity, needs)` to the history interface; overnight reset on `day_started`.

### The Lens — `PatternDeriver`

- New `features/case_file/pattern_rule.gd` (Resource), `Catalog`-loaded (**add `PatternRule` to the allowlist + dir**). Fields: `id`, an authored predicate over the history interface, the **trace fact** it yields, an `evidence_query` (stored now, surfaced Slice 2).
- New `features/case_file/pattern_deriver.gd` (RefCounted): evaluate loaded rules against the history interface each window; on a newly-true rule, emit the fact.
- **Output discipline (DD-030 / DD-031 — load-bearing):** PatternRule facts are **observational traces, never interpretations.** Allowed: *"No meals taken Mon–Wed," "Left the flat 0 times in 3 days," "Telescope filled 6 of 8 decisions."* Banned: *"Isolating," "Depressed," "Withdrawing."* The interpretation is the **player's** job — the desk shows the trace, the player reads the meaning. This keeps the game in observation mode, not reading-mode.

### Desk-fact channel — reconciliation (was a silent collision)

Tycoon **already** emits desk facts on `EventBus.case_file_updated` from **two** producers: random `World.try_surface_observation` (every 6h in `Sim.apply_tick`) and `ScheduledConsequence` (15 `obs_*.tres`). PatternDeriver is a third. **Decision for Slice 1:**
- **Retire** `try_surface_observation` (random pick) — it is a placeholder the deriver supersedes.
- **Keep** the scheduled-consequence path (authored, time-driven) but **tag fact provenance** (`derived` vs `authored`) on the entry so the desk never conflates "this was authored to happen" with "this was derived from emergent behavior." One source of truth per fact; no racing.

### Data flow

```
Clock.tick
  → Sim.apply_tick: decay; CAEngine.select → apply effects + mastery; history.append   [Elling lives]
  → PatternDeriver.evaluate(history): newly-true rule → EventBus.case_file_updated(fact, provenance=derived)
  → Desk renders trace facts                                                            [the read]
```
The CA-World is upstream of the Lens and never referenced by it; the deriver touches only the stable history interface, not engine internals.

## Deferred (named, not silent)

- **Lever / matlevering** → Slice 2. Channel-free single-agent matlevering is degenerate ("hunger sometimes restores") and re-proves the decay loop, not legibility. Levers land where they mean something (with Grete/the channel).
- **Paid evidence drill-down (tier 2)**, **dice / trust / moment tiltak** (full SDD-080 layer), **Grete + the dependency loop** (Slice 3+).
- **Watchable diorama.** World runs headless here. ⚠️ **Deliberate thesis probe, not a quiet cut:** "watching is satisfying" is a GDD-P0-validated pillar. Slice 1 tests whether the **desk-read alone** carries signal *with watching deferred*; this is an explicit, reversible divergence — if desk-reading proves thin, the watchable diorama returns as required, not optional.
- **Tuning gym** (sliders). Frozen preset only; full tuning surface is a follow-up convenience, not needed to answer the claim.
- Porting core-loop content packs (`tiny_olsen`).

## Ground Truth (for the gate)

The blind-read gate needs a hidden answer key. Today `agent_bridge` exposes `mtg_primary/secondary` under `reveal_hidden`. Slice 1 **re-points** the hidden truth at the new color-identity vector + the seeded need-trajectory; update `_client_snapshot` reveal_hidden and its GUT test accordingly.

## Designer Verification

### Tuning loop — eyeball (lightweight, frozen-preset)
A minimal harness (or the existing evaluator UI) shows the activity timeline ‖ derived trace facts over a seeded run, **plus an "uncovered behavior" channel**: decisions no rule fired on. This surfaces the **SB-294 invisibility trap** — emergent behavior the authored rules can't see is the failure mode, made visible so the designer closes the gap rather than shipping blind. (Full slider gym deferred.)

### Definition of done — blind-read rubric gate (tycoon's real harness)
Built on tycoon's actual stack: **GUT** for the deterministic plumbing + the **rubric evaluator** (`harness/run_evaluator.sh`, `test_rubric_schema.py`) for the judged read — **not** a "GATH gate" (tycoon has no GATH).
- Run the CA-World N seeded days headless.
- The reader (LLM-as-caseworker via `agent_bridge`, snapshot **redacted to derived facts only**) must name **the dominant problem** — i.e. the top need-deficit / behavioral fixation driving Elling — *without* echoing a fact label (facts are traces, not diagnoses, so a correct read requires interpretation, not parroting).
- Reveal the ground-truth log.
- **PASS = the read names the dominant problem on ≥ M of N seeds** (rubric-scored, fixed M/N — not fuzzy "matches"). Promote the exact M/N and seed list into the plan; they are the gate, not an open question.
- Red-green: stub PatternDeriver to emit a wrong/empty fact, confirm the gate fails, restore.

## Success Criteria

1. CA-World runs headless in tycoon; Elling autonomously selects varied, personality-expressing activities — **sandbox parity** vs `full_ca_sandbox.html` on the same preset (entropy / no death-spiral, per the sandbox's own metrics). core-loop's sandbox is the oracle for this check.
2. PatternDeriver emits **trace** facts via `EventBus.case_file_updated` (provenance-tagged `derived`); `try_surface_observation` retired; no raw activity and no authored *diagnoses* reach the desk.
3. "Uncovered behavior" channel works — emergent decisions with no firing rule are visible to the designer.
4. **Blind-read rubric gate passes** at the fixed M/N.

If (4) fails after honest authoring: the claim is **disproven cheaply**, before any economy/lever/Grete was built — a successful, repo-saving outcome. core-loop is NOT retired until (4) is green.
