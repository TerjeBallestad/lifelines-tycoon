PLAN-001 Task 18 ran the standalone blind-read gate (scripts/gate/blind_read_gate.py). The 5-seed M-of-N passed 5/5 with both fresh seeds, BUT the mandatory circularity red-green FAILED.

RED: stubbed features/case_file/pattern_deriver.gd _emit_derived() to emit nothing -> 0 derived facts -> reimport -> seed 747 STILL PASSED (named "Social isolation").

Root cause: build_prompt() injects the uncovered-behaviour channel as RAW activity_id counts. With the Lens disabled, nothing is "covered", so the reader receives act_use_telescope:13, act_do_crossword:5, etc. "telescope 13x" alone lets the LLM name isolation. The deriver output is therefore NOT load-bearing — the gate cannot fail when the production Lens is off.

redact_for_reader() (lines 248-265) honestly strips needs/cognitive/overskudd/overskudd_ceiling/colors and filters to provenance=="derived", but the uncovered channel bypasses that redaction.

Fix options: (a) redact the uncovered channel to coarse buckets / count-only with no activity-id labels, or (b) drop activity-ids from the prompt so the reader depends solely on provenance=="derived" titles. Then re-run the red-green: with the Lens stubbed the gate MUST fail. This blocks SDD-001 success criterion (4) and PLAN-001 Task 18 sign-off.
